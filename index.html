Method & limits — read this

This is a pointer measure, not proof a run built the thing. Each audit row is mapped to the latest journal section dated at or before it (headings like 12:2x are read as 12:20). A run counts as accounted when that section names an artifact slug from PROJECTS.md, matched on word boundaries. The errors run both ways, and both are visible here: a section that merely mentions an old artifact credits a run that shipped nothing, while a real artifact whose section forgot its name reads as burn. Runs before the first heading, and runs with no timestamp, never get credit. An unaccounted run is a question, not a verdict.
